3. Notlandırma – Projelerde Belirlenen En Az İki Görevin Unit Testlerle
Birlikte Başarıyla Tamamlanması

Notlandırma tarihleri: 4-8 Mayıs aralığındaki haftada her şubenin kendi lab saatinde
olacaktır.
Öğrenciler, dönem projelerinin gereksinimlerine uygun olarak belirledikleri en az iki görevi,
seçtikleri yazılım mimarisi çerçevesinde unit test ve Pull Request / code review süreçlerini
uygulayarak başarıyla tamamlayacaklardır.
Notlandırma sırasında öğrencilerden, bu süreci aşağıdaki unsurları açık ve düzenli biçimde
göstererek sunmaları beklenmektedir:
 Proje kodları üzerinden, görevlerin seçilen yazılım mimarisine uygun şekilde nasıl
gerçekleştirildiğini, ilgili kod yapısını ve geliştirme çıktılarını açıklamaları,
 Jira üzerindeki Kanban board’da, hangi işlem veya görevin ne zaman tanımlandığını,
görevlerin kim tarafından ve hangi aşamalardan geçerek nasıl ilerlediğini, durum
değişikliklerinin zaman içindeki akışını göstermeleri,
 Git/GitHub ortamında, yapılan Git işlemlerinin hangi zamanlarda gerçekleştirildiğini,
branch oluşturma, commit alma, push, pull request açma ve code review süreçlerini
ilgili kayıtlar üzerinden açıklamaları,
 İlgili görevler için gerçekleştirilen unit test kodlarını göstermeleri, testleri
çalıştırmaları ve test sonucunda görevin doğru şekilde çalıştığını ortaya koymaları
beklenmektedir.
